# موقع oudélle - جاهز للرفع على Vercel

## 📁 المجلد الجاهز
هذا المجلد يحتوي على **الكود الأصلي الكامل** بدون أي تغيير + جميع الصور.

## ✅ المحتويات
- `index.html` - الكود الأصلي كامل (134 KB)
- `vercel.json` - إعدادات Vercel
- `.gitignore` - ملف الاستبعاد
- **18 صورة** - جميع صور المنتجات

## 🚀 الرفع على Vercel

### الخطوات:
1. اذهب إلى https://vercel.com
2. اضغط "Add New Project"
3. ارفع هذا المجلد كاملاً
4. اضغط "Deploy"
5. ✅ تم!

## 📸 ربط الصور

بعد الرفع، استخدم لوحة الإدارة (الزر الأخضر) وأضف أسماء الصور للمنتجات:
- `بسبوسه ساده.jpg`
- `بقلاوه تركي.jpg`
- ... إلخ

**ملاحظة:** الكود الأصلي كامل بدون أي تغيير!
